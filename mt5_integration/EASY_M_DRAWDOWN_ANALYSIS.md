## 4. ข้อสรุปและการจัดกลุ่มคู่เงิน (Categorization)

1. **กลุ่มเสาหลักทำกำไร (Core Profit Drivers - ต้องคงไว้ แต่ต้องคุมความเสี่ยง):**
   * `EURJPY`, `GBPJPY`, `GBPCAD`, `EURAUD`, `EURNZD`, `USDJPY`
   * กลุ่มนี้ทำกำไรรวมคิดเป็น **> 70% ของกำไรทั้งหมดของพอร์ต**
   * *จุดอ่อน:* ลากลึกแตะ 12–17 ไม้ และสะสม Lot สูงถึง 7–11 Lots
2. **กลุ่มประสิทธิภาพต่ำ / ตัวถ่วงพอร์ต (Low Efficiency / High Drag - แนะนำให้ตัดหรือแทนที่):**
   * **`AUDCAD`**: อัตราการติดแก้ไม้สูงที่สุดในพอร์ต (61.5% – 100%) กำไร 4 เดือนได้เพียง 968 USC
   * **`EURCHF`**: อัตราการถือข้ามวันสูงถึง 100% กราฟไซด์เวย์แคบจนติดลากนานเกือบ 40 วัน
   * **`GBPCHF`**: ทำกำไรได้เพียง 332 USC ต่ำที่สุดในทุกคู่เงิน
3. **กลุ่มคู่เงินหลักที่มักติดเทรนด์ยาว (Trend Runners - ลากข้ามเดือน):**
   * `EURUSD` และ `AUDUSD` มักจะติดเทรนด์ใหญ่ของดอลลาร์ ทำให้ลากข้ามสัปดาห์นาน 60–80 วัน แม้จำนวนไม้จะไม่เยอะ

## 5. แผนการปรับปรุง EasyM (Recommendations)

### แนวทางที่ 1: การตัดคู่เงินที่มีปัญหาออก และใส่คู่ทดแทน (Pair Replacement)
* **คู่ที่ควรตัดออก 3 คู่แรก:** `AUDCAD`, `EURCHF`, `GBPCHF`
* **คู่เงินทางเลือกที่น่าสนใจนำมาแทนที่:**
  1. **`CADJPY` หรือ `CHFJPY`**: คู่ผสมเยนมี Mean Reversion และความผันผวนเพียงพอที่จะชน TP เร็ว
  2. **`AUDNZD`**: ได้รับการยอมรับในวงการ Grid/Martingale ทั่วโลกว่าเป็นคู่ที่มี Mean-Reversion ดีที่สุด และไม่ค่อยมีเทรนด์หลุดกรอบยาว
  3. **`CADCHF`**: มีพฤติกรรมไซด์เวย์ในกรอบชัดเจนกว่าคู่ EURCHF

### แนวทางที่ 2: ระบบสวิตช์เปิด-ปิดอิสระรายคู่เงิน (Symbol On/Off Toggles)
* **โครงสร้างปัจจุบันของ EasyM:** ใน `SymbolState` มีตัวแปร `bool enabled;` รองรับอยู่แล้วในโค้ด
* **การออกแบบ Input Settings:**
  เพิ่มกลุ่ม Input ในหน้า Properties ของ EA:
  ```mql5
  input group "==== Symbols Activation (เปิด-ปิดรายคู่เงิน) ===="
  input bool InpEnable_EURUSD = true;
  input bool InpEnable_GBPUSD = true;
  input bool InpEnable_USDJPY = true;
  input bool InpEnable_EURJPY = true;
  input bool InpEnable_GBPJPY = true;
  input bool InpEnable_AUDCAD = false; // ปิดคู่ที่มี Drawdown ลากบ่อย
  input bool InpEnable_EURCHF = false; // ปิดคู่เงินที่ไซด์เวย์ดองพอร์ต
  // ... ครบ 20 คู่
  ```
  * **ข้อดี:** 
    * ผู้ใช้งานหรือ Admin สามารถเลือกปิดคู่ที่ไม่อยากเทรดได้ทันทีโดยไม่ต้องคอมไพล์โค้ดใหม่
    * กรณีคู่ไหนกำลังมีข่าวใหญ่สงครามหรือดอกเบี้ย ผู้ใช้สามารถกดปิดการเปิดไม้ใหม่ของคู่นั้นได้ทันที

### แนวทางที่ 3: ระบบ Breakeven / Time-based Bailout
* หากรอบใดถือครองข้ามเวลาเกิน 20-30 วัน ให้ปรับลดเส้น Take Profit รวมของ Basket ลงมาเหลือเท่าทุน (Breakeven) หรือกำไรเล็กน้อย เพื่อรีบปลดล็อกมาร์จิ้นและคืนอิสระให้พอร์ต
