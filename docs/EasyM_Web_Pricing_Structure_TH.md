# EasyM Pricing & Customer Journey Specification

เอกสารนี้ใช้เป็นต้นฉบับสำหรับให้ AI ออกแบบและสร้างหน้าเว็บเลือกแพ็กเกจ EasyM โดยต้องทำให้ลูกค้าเลือกได้ง่ายทีละขั้น ไม่แสดงตัวเลือกทั้งหมดพร้อมกัน

## 1. เป้าหมายของหน้าเว็บ

สร้างหน้าเลือกแพ็กเกจแบบ 3 ขั้นตอน:

1. เลือกประเภทลูกค้า: **ลูกค้าเดิม** หรือ **ลูกค้าใหม่**
2. เลือกวิธีดูแลระบบ: **รันบน VPS ของตัวเอง** หรือ **ให้ทีม EasyM รันและดูแลให้**
3. เลือก EA: **mini, MAX หรือ PRIME** ตามตัวเลือกที่ใช้ได้ พร้อมแสดงรายละเอียด ราคา และสิทธิ์ที่ได้รับ

หน้าเว็บควรซ่อนตัวเลือกที่ไม่เกี่ยวข้อง และแสดงสรุปราคาแบบอัปเดตทันทีเมื่อผู้ใช้เลือกแต่ละขั้นตอน

---

## 2. กติกากลางของระบบราคา

- ราคาทั้งหมดเป็น **ราคาต่อปี**
- ราคาเริ่มต้นใช้บัญชีเทรดที่สมัครผ่าน **IB ของ EasyM**
- หากลูกค้าต้องการใช้โบรกเกอร์หรือบัญชีเดิมของตัวเอง ให้เพิ่มค่าปลดล็อก **4,000 บาท/ปี**
- EasyM mini มีเฉพาะแบบรันบน VPS ของลูกค้าเอง ไม่มี Farm UI
- ลูกค้าที่ใช้ MAX หรือ PRIME และมี Farm UI จะทดลองใช้ Farm UI ได้ **2 เดือน** ก่อนเริ่มแพ็กเกจรายปี
- MAX ใช้ **Standard Farm UI** สำหรับดูสถานะและติดตามการทำงาน
- PRIME ใช้ **Advanced Farm UI** ดูสถานะและสั่งเปิด–ปิดคู่เงินจากหน้าเว็บได้ พร้อมรองรับฟีเจอร์ใหม่ เช่น การแจ้งเตือนและการตั้งค่าผ่านเว็บในอนาคต
- แพ็กเกจที่ EasyM ดูแลให้ รวมการรันระบบบน VPS ของ EasyM ลูกค้าใช้งานผ่านหน้าเว็บเป็นหลัก
- ราคาแต่ละรายการใช้กับ **1 พอร์ต/1 บัญชีเทรด**

> หมายเหตุสำหรับหน้าเว็บ: ให้แสดงตัวเลือก “ใช้โบรกเกอร์ของตัวเอง +4,000 บาท/ปี” เป็นสวิตช์หรือ Add-on หลังจากลูกค้าเลือกแพ็กเกจแล้ว

# เส้นทางที่ 1: ลูกค้าเดิม

คำอธิบายบนหน้าเว็บ:

**สำหรับลูกค้า EasyM ที่ใช้งานอยู่ก่อนเริ่มระบบราคาใหม่ รับสิทธิ์ใช้ต่อในราคาเดิมหรืออัปเกรดในราคาพิเศษ**

## ขั้นที่ 2A: ลูกค้าเดิมรันบน VPS ของตัวเอง

ลูกค้าดูแล VPS และระบบเทรดเอง จากนั้นเลือก EA ได้ดังนี้

### ตัวเลือก A1 — EasyM mini เดิม

- ราคา: **ฟรี**
- ใช้ VPS ของลูกค้าเอง
- สมัครผ่าน IB ของ EasyM
- ไม่มี Farm UI
- เหมาะสำหรับพอร์ตเริ่มต้นและผู้ที่ต้องการระบบเรียบง่าย

### ตัวเลือก A2 — EasyM MAX แบบเดิม

- ราคา: **ฟรี**
- ใช้ VPS ของลูกค้าเอง
- สมัครผ่าน IB ของ EasyM
- ไม่มี Farm UI
- ลูกค้าสามารถกลับไปใช้งานในรูปแบบเดิมได้หลังจบช่วงทดลอง Farm UI

### ตัวเลือก A3 — EasyM MAX + Standard Farm UI

- ราคา: **4,000 บาท/ปี**
- ใช้ VPS ของลูกค้าเอง
- มี Standard Farm UI สำหรับติดตามพอร์ตผ่านเว็บ
- เหมาะสำหรับลูกค้าเดิมที่ต้องการดูระบบได้สะดวกขึ้น แต่ยังต้องการดูแล VPS เอง

### ตัวเลือก A4 — อัปเกรดเป็น EasyM PRIME

- ราคาพิเศษลูกค้าเดิม: **8,000 บาท/ปี**
- ใช้ VPS ของลูกค้าเอง
- รวม Advanced Farm UI
- สั่งเปิด–ปิดคู่เงินจากหน้าเว็บได้
- เอกสิทธิ์ความปลอดภัย: **Safe Liquidation Protocol** (เมื่อหมดสัญญา ระบบดูแลปิดรวบออเดอร์เดิมให้ปลอดภัยจนหมด ไม่เปิดไม้ใหม่ และไม่ลอยแพพอร์ต)
- รองรับฟีเจอร์ใหม่และการควบคุมผ่านเว็บในอนาคต
- ข้อความแนะนำบนการ์ด: **Recommended Upgrade**

## ขั้นที่ 2B: ให้ EasyM รัน VPS และดูแลระบบให้

ลูกค้าไม่ต้องดูแล VPS เอง ทีม EasyM รันและดูแลหลังบ้านให้ ลูกค้าติดตามผ่าน Farm UI

### ตัวเลือก B1 — EasyM MAX Managed

- ราคาพิเศษลูกค้าเดิม: **6,000 บาท/ปี**
- ราคาปกติสำหรับลูกค้าใหม่: 12,000 บาท/ปี
- รวม VPS และการดูแลระบบโดย EasyM
- รวม Standard Farm UI
- เหมาะสำหรับลูกค้าเดิมที่ต้องการลดภาระดูแลระบบในราคาประหยัด

### ตัวเลือก B2 — EasyM PRIME Managed

- ราคาพิเศษสำหรับลูกค้า MAX เดิมที่อัปเกรด: **12,000 บาท/ปี**
- ราคาปกติสำหรับลูกค้า PRIME ใหม่: 15,000 บาท/ปี
- รวม VPS และการดูแลระบบโดย EasyM
- รวม Advanced Farm UI
- สั่งเปิด–ปิดคู่เงินผ่านหน้าเว็บได้
- เอกสิทธิ์ความปลอดภัย: **Safe Liquidation Protocol** (เมื่อหมดสัญญา ระบบดูแลปิดรวบออเดอร์เดิมให้ปลอดภัยจนหมด ไม่เปิดไม้ใหม่ และไม่ลอยแพพอร์ต)
- รองรับฟีเจอร์ใหม่ เช่น การแจ้งเตือนและการตั้งค่าผ่านเว็บในอนาคต
- ข้อความแนะนำบนการ์ด: **Best Value for Existing Customers**

> ไม่เสนอ EasyM mini ในแบบ EasyM Managed เพราะ mini เป็นรุ่นฟรีสำหรับลูกค้าที่ติดตั้งและดูแล VPS เอง

# เส้นทางที่ 2: ลูกค้าใหม่

คำอธิบายบนหน้าเว็บ:

**เริ่มต้นง่าย เลือกให้เหมาะกับระดับพอร์ตและรูปแบบการดูแลที่ต้องการ แพ็กเกจ MAX และ PRIME มาพร้อม Farm UI เป็นระบบเดียวกัน**

## ขั้นที่ 2A: ลูกค้าใหม่รันบน VPS ของตัวเอง

ลูกค้ามี VPS และรับผิดชอบการติดตั้งหรือดูแลระบบเอง

### ตัวเลือก C1 — EasyM mini Free

- ราคา: **ฟรี**
- ใช้ VPS ของลูกค้าเอง
- ต้องสมัครผ่าน IB ของ EasyM
- ไม่มี Farm UI
- เหมาะสำหรับผู้เริ่มต้นหรือพอร์ตขนาดเล็ก

### ตัวเลือก C2 — EasyM MAX Free

- ราคา: **ฟรี**
- ใช้ VPS ของลูกค้าเอง
- ต้องสมัครผ่าน IB ของ EasyM
- ไม่มี Farm UI
- เหมาะสำหรับผู้ที่ต้องการใช้งาน MAX แต่ดูแลระบบและตรวจสอบผ่าน Dashboard ภายใน EA เอง

### ตัวเลือก C3 — EasyM MAX System

- ราคา: **8,000 บาท/ปี**
- ใช้ VPS ของลูกค้าเอง

- เหมาะสำหรับผู้ที่ต้องการ MAX พร้อมติดตามหลายพอร์ตผ่านเว็บ

### ตัวเลือก C4 — EasyM PRIME System

- ราคา: **10,000 บาท/ปี**
- ใช้ VPS ของลูกค้าเอง
- รวม Advanced Farm UI
- ทดลองใช้ Farm UI 2 เดือน
- สั่งเปิด–ปิดคู่เงินจากหน้าเว็บได้
- เอกสิทธิ์ความปลอดภัย: **Safe Liquidation Protocol** (เมื่อหมดสัญญา ระบบดูแลปิดรวบออเดอร์เดิมให้ปลอดภัยจนหมด ไม่เปิดไม้ใหม่ และไม่ลอยแพพอร์ต)
- พร้อมรับฟีเจอร์ควบคุมและการแจ้งเตือนใหม่ในอนาคต
- ข้อความแนะนำบนการ์ด: **More Control, More Protection**

## ขั้นที่ 2B: ให้ EasyM รัน VPS และดูแลระบบให้

ทีม EasyM ดูแลการรันระบบบน VPS ให้ทั้งหมด ลูกค้าติดตามผลผ่านหน้าเว็บ

- ลูกค้าไม่ต้องเปิด VPS หรือดูแลระบบประจำวันเอง

### ตัวเลือก D2 — EasyM PRIME Managed

- ลูกค้าเดิมอัปเกรด PRIME Managed และใช้โบรกเกอร์ตัวเอง: 12,000 + 4,000 = **16,000 บาท/ปี**

## 4. โครงสร้างหน้าจอที่ต้องการ

### ส่วนบนของหน้า

- หัวข้อ: **Choose Your EasyM Plan**
- คำอธิบาย: **เลือกตามสถานะลูกค้า วิธีดูแลระบบ และระดับ EA ที่เหมาะกับคุณ**
- แสดง Step Progress: `1. Customer Type → 2. VPS Management → 3. Choose Your EA`

### Step 1 — Customer Type

แสดงการ์ด 2 ใบ:

1. **Existing Customer — ลูกค้าเดิม**  
   รับสิทธิ์ใช้ต่อหรืออัปเกรดในราคาพิเศษ
2. **New Customer — ลูกค้าใหม่**  
   เริ่มต้นด้วยแพ็กเกจที่รวมระบบและ Farm UI

### Step 2 — VPS Management

แสดงการ์ด 2 ใบ:

1. **Run on My VPS — ฉันดูแล VPS เอง**  
   เหมาะกับผู้ที่มี VPS และจัดการระบบเองได้
2. **EasyM Managed — ให้ EasyM ดูแลให้**  
   เรารัน VPS และดูแลหลังบ้าน ลูกค้าติดตามผ่านเว็บ

### Step 3 — Choose Your EA

- แสดงเฉพาะแพ็กเกจที่ตรงกับ Step 1 และ Step 2
- การ์ดแต่ละใบต้องมีชื่อ EA, จุดเด่นสั้นๆ, Farm UI ที่ได้รับ, ราคา/ปี และปุ่มเลือก
- ทำการ์ด **PRIME Managed** ให้เด่นที่สุด
- สำหรับลูกค้าเดิม ให้แสดงราคาพิเศษคู่กับราคาปกติเพื่อให้เห็นความคุ้มค่า

### Add-on หลังเลือกแพ็กเกจ

แสดงคำถาม:

**บัญชีเทรดของคุณสมัครผ่าน IB ของ EasyM หรือไม่?**

- สมัครผ่าน IB EasyM — ไม่มีค่าใช้จ่ายเพิ่ม
- ใช้โบรกเกอร์/บัญชีของตัวเอง — เพิ่ม 4,000 บาท/ปี

### กล่องสรุปคำสั่งซื้อ

แสดงข้อมูลต่อไปนี้แบบอัปเดตทันที:

- ประเภทลูกค้า
- ผู้ดูแล VPS
- EA และแพ็กเกจที่เลือก
- ประเภท Farm UI
- ราคาแพ็กเกจ
- ค่า Own Broker Unlock ถ้ามี
- ยอดรวมต่อปี
- ราคาเฉลี่ยต่อเดือนเพื่อช่วยให้ตัดสินใจง่าย
- ปุ่มหลัก: **Start 2-Month Trial** สำหรับ MAX/PRIME ที่มี Farm UI
- ปุ่มหลัก: **Start Free** สำหรับ mini/MAX Free ที่ไม่มี Farm UI

## 5. Logic ที่ AI/ผู้พัฒนาต้องปฏิบัติตาม

1. ถ้าเลือก **EasyM Managed** ให้ซ่อน mini เสมอ
2. ถ้าเลือกแพ็กเกจ Free ให้แสดงว่าไม่มี Farm UI และลูกค้าต้องมี VPS เอง
3. ถ้าเลือก MAX แบบเสียเงิน ให้แสดง Standard Farm UI
4. ถ้าเลือก PRIME ให้แสดง Advanced Farm UI และความสามารถควบคุมคู่เงินผ่านเว็บ
5. ถ้าเป็นลูกค้าเดิม ให้ใช้ราคาลูกค้าเดิมตามตารางเท่านั้น
6. ถ้าเป็นลูกค้าใหม่ ให้ใช้ราคาลูกค้าใหม่ตามตารางเท่านั้น
7. เมื่อเปิดตัวเลือกใช้โบรกเกอร์ของตัวเอง ให้บวก 4,000 บาทกับยอดรวมทันที
8. Trial 2 เดือนใช้กับแพ็กเกจ MAX/PRIME ที่มี Farm UI ไม่ใช้กับ mini หรือ MAX Free
9. อย่าแสดงตัวเลือกเกินหนึ่งขั้นพร้อมกันบนมือถือ ให้ลูกค้าตัดสินใจทีละขั้น
