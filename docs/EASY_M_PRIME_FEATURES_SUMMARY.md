* [x] **Smart Heartbeat & Bandwidth Optimizer:** ปรับความถี่การส่งข้อมูลอัจฉริยะ (ส่งทุก 3 นาทีเมื่อไม่มีคนดูเว็บ และสลับเป็น 20 วินาทีอัตโนมัติเฉพาะตอนลูกค้าเปิดดูหน้าฟาร์ม) ประหยัดเน็ต VPS และ CPU สูงถึง 90%
* [x] **Timeout 1003 Immunity (Auto-Retry Protocol):** ขยายเวลา Timeout เป็น 10,000 ms (10 วินาที) พร้อมระบบดักจับรหัส 1003 และกู้คืนการเชื่อมต่อใหม่อัตโนมัติ ปราศจากเสียงแจ้งเตือนข้อผิดพลาดกวนใจ
* [x] **Multi-Account & Prop-Firm Compatibility:** ออกแบบให้รันได้ทั้งพอร์ต Cent (USC) และ Standard (USD) รองรับขนาดสัญญาและทศนิยมของทุกโบรกเกอร์ระดับสากล

### 2. เครื่องยนต์การเทรด 20 คู่เงิน (20-Pair Multi-Currency Engine)
* [x] **20 Major & Cross Currency Basket:** บรรจุคู่เงินคัดสรรคุณภาพ 20 คู่ กระจายความเสี่ยงเต็มแผง ลดการพึ่งพากำไรจากคู่ใดคู่หนึ่ง (EURUSD, GBPUSD, AUDUSD, NZDUSD, USDJPY, USDCHF, EURJPY, GBPJPY, USDCAD, AUDNZD, CADCHF, NZDCAD, EURCAD, GBPCAD, EURAUD, GBPAUD, AUDJPY, NZDJPY, EURNZD, GBPNZD)
* [x] **Adaptive Volatility Filter:** คัดกรองจังหวะเข้าออเดอร์ด้วยการคำนวณ RSI Oversold/Overbought ควบคู่กับรูปแบบแท่งเทียน Reversal ไส้ยาว เพื่อเข้าไม้แรกที่จุดกลับตัวของราคา
* [x] **Currency Cluster Limiter (ปลดล็อกเป็น 3 คู่ใน Build 1006):** ระบบควบคุมความเสี่ยงเชิงลึก จำกัดไม่ให้ถือครองออเดอร์ในกลุ่มสกุลเงินเดียวกัน (Currency Exposure) เกิน 3 คู่พร้อมกัน เพิ่มโอกาสสร้างกระแสเงินสด (Cash Flow) ให้พอร์ตอย่างเต็มประสิทธิภาพ โดยไม่ถูกบล็อกโอกาสจากสกุลเงินร่วมที่มีมากถึง 7 คู่ (USD), 6 คู่ (NZD), 5 คู่ (JPY, EUR, GBP, AUD, CAD) ขณะที่ยังคงความปลอดภัยระดับสูงสุดด้วยระบบนิรภัย 5 ชั้นของ Prime
* [x] **Smart Dynamic Grid Spacing:** ปรับระยะห่างของการเปิดไม้แก้ (Averaging Step) ยืดหยุ่นตามระยะทางและความผันผวนของกราฟ ไม่ถมไม้ถี่เกินไปในภาวะเทรนด์รุนแรง
* [x] **Basket Take Profit Consolidation:** รวมต้นทุนไม้แก้ทั้งหมดและคำนวณจุด Take Profit สุทธิเพียงจุดเดียว เมื่อราคาเด้งกลับเพียงเล็กน้อยระบบจะปิดรวบทั้งตะกร้าทันที

### 3. ระบบควบคุมความเสี่ยงพอร์ต 3 ระดับ (Port Mode Safety Control)
* [x] **NORMAL MODE (โหมดปกติ):** รันเปิดไม้และแก้ไม้ตามกลยุทธ์มาตรฐานเต็มประสิทธิภาพ
* [x] **SLOW MODE (โหมดชะลอความเร็ว):** เมื่อ Drawdown พอร์ตเริ่มขยับสูงขึ้น ระบบจะขยายระยะห่างไม้แก้ให้กว้างขึ้น เพื่อประหยัด Margin และรักษาความปลอดภัยของพอร์ต
* [x] **FREEZE MODE (โหมดแช่แข็ง):** ระงับการเปิดไม้ใหม่ของทุกคู่เงินโดยสิ้นเชิงเมื่อพอร์ตเผชิญภาวะผันผวนหนัก รอเคลียร์ออเดอร์ชุดเดิมให้เสร็จสิ้นก่อน
* [x] **Delta=0 Auto-Hedge Lock (Hard Cap 40% DD):** ปราการด่านสุดท้าย เมื่อพอร์ตติดลบแตะระดับวิกฤต ระบบจะคำนวณและเปิดสถานะสวนทางแบบสุทธิ (Net Delta = 0) ล็อก Drawdown คงที่ทันทีเพื่อป้องกันพอร์ตแตก 100%

---

### 4. ระบบห้องขังเดี่ยว & สไนเปอร์กู้ภัย (Quarantine & Sniper Rescue Grid)
* [x] **Auto Quarantine Isolation (DD เดี่ยวแตะ 10-11%):** เมื่อคู่เงินใดคู่เงินหนึ่งถูกลากจน Drawdown เฉพาะคู่นั้นแตะ 10% ระบบจะสั่ง "กักขังเดี่ยว" ทันที โดยหยุดถมไม้เพิ่มในคู่นั้นโดยเด็ดขาด ปล่อยให้คู่ที่เหลือทำกำไรต่อได้อย่างอิสระ
* [x] **Sniper Rescue R1 & R2 Grid:** ขณะที่คู่เงินอยู่ในห้องขัง ระบบจะเปิดเรดาร์คำนวณจุดกลับตัวระดับ Macro Timeframe เพื่อส่งไม้กู้ภัย "Sniper Rescue" เข้าทำกำไรดึงเส้น Take Profit รวมให้ลงมาใกล้ราคาปัจจุบันเร็วขึ้น 3 เท่า
* [x] **Safe Quarantine Exit Validation:** ตรวจจับผลกำไรจากการปิดดีลจริง (Closed Deal Profit) และรีเซ็ตสถานะคู่เงินออกจากห้องขังเฉพาะเมื่อเคลียร์ออเดอร์ได้สำเร็จจริง พร้อมแจ้งข้อความ `Released from Quarantine!` ใน Log อย่างแม่นยำ

### 5. กองทุนตัดขาดทุนข้ามคู่ (Cross-Pair Relief Fund & Profit Slicing)
* [x] **Profit Slicing Vault (40% Slicing):** ทุกครั้งที่คู่เงินอื่นๆ ปิดทำกำไรได้สำเร็จ ระบบจะหักแบ่งสัดส่วนกำไร 40% โอนเข้าสู่ "กองทุนกลาง (Relief Fund Vault)" สะสมไว้ในหน่วยความจำ
* [x] **Self-Healing Position Trimming:** นำกำไรที่สะสมในกองทุน ไปทยอยตัดปิดขาดทุนไม้ที่แย่ที่สุด (Worst Order) ของคู่ที่ติดอยู่ในห้องขังทีละไม้ โดยที่ Balance รวมของพอร์ตไม่ลดลงและไม่ต้องเติมเงินเข้าพอร์ตแม้แต่บาทเดียว
* [x] **Fund Balance Tracking on HUD:** แสดงยอดเงินกองทุนสะสมที่พร้อมใช้งาน (`FUND: XX.XX`) บนหน้าจอ Dashboard ให้เห็นแบบ Real-time ตลอดเวลา

### 6. ระบบปิดรอบปลอดภัยเมื่อหมดสัญญา (Safe Liquidation Protocol - เอกสิทธิ์เฉพาะ PRIME)
* [x] **No Stranded Positions (ไม่ปล่อยพอร์ตเคว้งคว้าง):** หากระยะเวลาสัญญาการใช้งานของลูกค้าหมดลง หรือสิทธิ์ถูกระงับ EA จะไม่สั่งปิด Cut Loss ขาดทุนทันที และจะไม่หยุดทำงานทิ้งออเดอร์ค้างไว้
* [x] **Close-Only Transition:** สลับพอร์ตเข้าสู่โหมด Safe Liquidation อัตโนมัติ โดยระงับการเปิดไม้แรกและไม้แก้ใหม่ 100%
* [x] **Managed Basket Exit:** เฝ้าบริหารจัดการจุดปิดทำกำไรรวมของออเดอร์เดิมที่ถืออยู่จนกว่าจะปิดจบครบทุกไม้ด้วยความปลอดภัยสูงสุด
* [x] **Self-Detaching `ExpertRemove()`:** เมื่อตรวจสอบว่าออเดอร์ในพอร์ตปิดหมดจนเหลือ 0 (`OrdersTotal() == 0`) ตัวบอทจะสั่งถอดตัวเองออกจากกราฟ MT5 ทันทีอย่างปลอดภัย ป้องกันปัญหาพอร์ตค้างหรือการแอบรันฟรี

### 7. แดชบอร์ดมอนิเตอร์บนกราฟ MT5 (On-Chart Interactive Cyber Deck)
* [x] **3D Raised/Depressed Clickable Buttons (ปุ่มนูน/ยุบ 20 คู่เงิน):**
  * ชื่อคู่เงินแต่ละช่องแสดงผลเป็นปุ่ม 3 มิติ สามารถ **ใช้เมาส์คลิกเพื่อเปิด-ปิดการทำงานรายคู่** ได้โดยตรงจากบนกราฟ
  * **ปุ่มนูน (Raised) สีเขียว/ทอง:** สถานะเปิดทำงาน (Active)
  * **ปุ่มยุบ (Depressed) สีเทาเข้ม:** สถานะสั่งปิดการทำงาน (Disabled / Close-Only)
* [x] **20-Pair VU Meters & Center PnL Bars:** แสดงขีดความหนาแน่นจำนวนไม้ และหลอดกราฟิกผลกำไร/ขาดทุนที่แผ่ออกจากจุดศูนย์กลาง ช่วยให้อ่านสุขภาพของแต่ละคู่เงินได้ในเสี้ยววินาที
* [x] **Signal Radar Indicators:** จุดไฟสถานะ `B` (ฟ้า) และ `S` (ทอง) แจ้งเตือนเมื่อคู่เงินนั้นเข้าสูตรเตรียมเปิดไม้
* [x] **Worst Pair Tracker:** แสดงชื่อคู่เงินที่กำลังติดลบสูงที่สุดในพอร์ตแบบเรียลไทม์ เพื่อให้ผู้ใช้งานจับตาดูการแก้ไม้ได้ทันที
* [x] **Full Metrics Header:** สรุปยอด Balance, Equity, DD%, Lots รวม, จำนวน Orders ทั้งหมด และกำไรสุทธิวันนี้ (Today P/L) ไว้อย่างชัดเจน

## 🔄 บันทึกการเปลี่ยนแปลงคู่เงิน: จาก EasyM MAX สู่ EasyM PRIME

ในการยกระดับจาก **EasyM MAX** สู่ **EasyM PRIME (v2.00)** ได้มีการปรับปรุงตะกร้า 20 คู่เงิน โดย **ถอด 3 คู่เดิม** ที่มีความเสี่ยงทางสถิติสูงออก และ **นำ 3 คู่ใหม่** ที่มีพฤติกรรม Mean-Reversion ดีเยี่ยมเข้ามาแทนที่ ดังนี้:

### 🔻 1. คู่เงินที่นำออกจาก MAX (ย้ายไปเป็น Legacy Close-Only)
1. **`AUDCAD`**
   - **พฤติกรรมเดิมใน MAX:** เกิดเทรนด์ทางเดียวบ่อย ลากยาวไม่ยอมย่อตัว (Lack of Mean Reversion)
   - **เหตุผลที่นำออก:** แม้ทั้งสองสกุลจะเป็น Commodity Currency แต่ CAD มีความสัมพันธ์แนบแน่นกับราคาน้ำมันดิบโลก (Crude Oil) สูงมาก ในช่วงที่ราคาน้ำมันพุ่งแรง CAD จะแข็งค่าฉีกหนี AUD เกิดเป็น Super Trend ทางเดียว ทำให้กริดติดหล่มและ Drawdown ค้างนาน
2. **`EURCHF`**
   - **พฤติกรรมเดิมใน MAX:** กราฟแกว่งตัวแคบเกินไป (Low Volatility / Narrow Range) สภาพคล่องต่ำ
   - **เหตุผลที่นำออก:** เมื่อ Range ราคาแคบ ทำให้รอบการปิดรวบทำกำไร (Cycle Turnover) ช้ามาก เงินจม และมีความเสี่ยงเรื่องธนาคารกลางสวิส (SNB) เข้าแทรกแซงค่าเงิน รวมถึงค่า Swap ติดลบสูง ไม่คุ้มค่า Margin ในระยะยาว
3. **`GBPCHF`**
   - **พฤติกรรมเดิมใน MAX:** มีความผันผวนกระชากรุนแรง (Extreme Tail Risk)
   - **เหตุผลที่นำออก:** ค่าเงินปอนด์ (GBP) มีความอ่อนไหวต่อข่าวเศรษฐกิจและการเมืองสูงมาก เมื่อจับคู่กับฟรังก์สวิส (CHF) ซึ่งเป็นสินทรัพย์ Safe-Haven ในยามวิกฤตจะเกิดแรงกระชากดิ่งลงลึกมาก เป็นคู่เงินที่เคยสร้าง Drawdown สูงที่สุดในประวัติศาสตร์ของ EasyM MAX เดิม

### 🟢 2. คู่เงินใหม่ที่เพิ่มเข้ามาใน EasyM PRIME
1. **`AUDNZD` (เข้ามาแทน `AUDCAD`)**
   - **คุณสมบัติ:** ได้รับการยอมรับในวงการ Quant Trading ว่าเป็น **"#1 Grid Trading Pair in Forex"**
   - **เหตุผลที่เลือกใช้:** ออสเตรเลียและนิวซีแลนด์มีโครงสร้างเศรษฐกิจ นโยบายดอกเบี้ยธนาคารกลาง และภูมิศาสตร์การค้าแนบแน่นเกือบเหมือนกัน 100% ทำให้ราคาของ AUDNZD มีพฤติกรรมแกว่งตัวไซด์เวย์ในกรอบสม่ำเสมอที่สุด (Strong Mean-Reversion) มีโอกาสวิ่งเป็นเทรนด์ทางเดียวยาวๆ น้อยที่สุด ปลอดภัยสูงสุดสำหรับระบบ Grid
2. **`CADCHF` (เข้ามาแทน `EURCHF`)**
   - **คุณสมบัติ:** **"Wide Oscillation & Balanced Risk"**
   - **เหตุผลที่เลือกใช้:** มีระยะสวิงของกรอบราคากว้างและสุขภาพดีกว่า EURCHF ชัดเจน มีแรงดึงกลับระหว่าง CAD (Risk-on / Oil) กับ CHF (Safe-haven) ที่สมดุล ทำให้มีรอบการเปิดและปิดรวบไม้ทำกำไรได้สม่ำเสมอกว่า ไม่ค้างตายนาน

   - **เหตุผลที่เลือกใช้:** ทั้งสองสกุลเป็นคู่เงินสินค้าโภคภัณฑ์ (Commodity Cross) มีจังหวะการแกว่งตัวที่นุ่มนวลและเป็นระเบียบกว่า GBPCHF อย่างเห็นได้ชัด ตัดความเสี่ยงเรื่องแรงกระชากรุนแรง (Flash Crash) ของค่าเงินปอนด์ออกไป ช่วยลด Maximum Drawdown ของพอร์ตรวมได้อย่างมีนัยสำคัญ
