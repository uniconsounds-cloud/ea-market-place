### 2. เครื่องยนต์การเทรด 20 คู่เงิน (20-Pair Multi-Currency Engine)
* [x] **20 Major & Cross Currency Basket:** บรรจุคู่เงินคัดสรรคุณภาพ 20 คู่ กระจายความเสี่ยงเต็มแผง ลดการพึ่งพากำไรจากคู่ใดคู่หนึ่ง (EURUSD, GBPUSD, AUDUSD, NZDUSD, USDJPY, USDCHF, EURJPY, GBPJPY, USDCAD, AUDNZD, CADCHF, NZDCAD, EURCAD, GBPCAD, EURAUD, GBPAUD, AUDJPY, NZDJPY, EURNZD, GBPNZD)
* [x] **Adaptive Volatility Filter:** คัดกรองจังหวะเข้าออเดอร์ด้วยการคำนวณ RSI Oversold/Overbought ควบคู่กับรูปแบบแท่งเทียน Reversal ไส้ยาว เพื่อเข้าไม้แรกที่จุดกลับตัวของราคา
* [x] **Currency Cluster Limiter (ปลดล็อกเป็น 3 คู่ใน Build 1006):** ระบบควบคุมความเสี่ยงเชิงลึก จำกัดไม่ให้ถือครองออเดอร์ในกลุ่มสกุลเงินเดียวกัน (Currency Exposure) เกิน 3 คู่พร้อมกัน เพิ่มโอกาสสร้างกระแสเงินสด (Cash Flow) ให้พอร์ตอย่างเต็มประสิทธิภาพ โดยไม่ถูกบล็อกโอกาสจากสกุลเงินร่วมที่มีมากถึง 7 คู่ (USD), 6 คู่ (NZD), 5 คู่ (JPY, EUR, GBP, AUD, CAD) ขณะที่ยังคงความปลอดภัยระดับสูงสุดด้วยระบบนิรภัย 5 ชั้นของ Prime
* [x] **Smart Dynamic Grid Spacing:** ปรับระยะห่างของการเปิดไม้แก้ (Averaging Step) ยืดหยุ่นตามระยะทางและความผันผวนของกราฟ ไม่ถมไม้ถี่เกินไปในภาวะเทรนด์รุนแรง
* [x] **Basket Take Profit Consolidation:** รวมต้นทุนไม้แก้ทั้งหมดและคำนวณจุด Take Profit สุทธิเพียงจุดเดียว เมื่อราคาเด้งกลับเพียงเล็กน้อยระบบจะปิดรวบทั้งตะกร้าทันที

### 3. ระบบควบคุมความเสี่ยงพอร์ตและรายคู่เงิน (Port Mode & Symbol Throttle)
* [x] **3-Tier Portfolio Mode Safety Control:**
  * **NORMAL MODE (โหมดปกติ):** รันเปิดไม้และแก้ไม้ตามกลยุทธ์มาตรฐานเต็มประสิทธิภาพ
  * **SLOW MODE (โหมดชะลอความเร็ว - DD พอร์ตแตะ 18.0%):** ปรับลดการเปิดคู่ใหม่เหลือ 4 คู่, จำกัดคู่ Active รวม 6 คู่ และขยายระยะห่างไม้แก้เพื่อประหยัด Margin
  * **FREEZE MODE (โหมดแช่แข็ง - DD พอร์ตแตะ 28.0%):** ระงับการเปิดไม้ใหม่ของทุกคู่เงินโดยสิ้นเชิง (0 คู่ใหม่) รอเคลียร์ออเดอร์ชุดเดิมให้เสร็จสิ้นก่อน
  * **Hysteresis Resume (ปลดกลับ NORMAL - DD พอร์ตต่ำกว่า 12.0%):** ป้องกันการแกว่งติดๆ ดับๆ ตามแนวรับต้าน
* [x] **Symbol Worst Throttle (ควบคุมความเสี่ยงรายคู่เงิน Top 4 คู่):**
  * **Slow รายคู่ (DD คู่แตะ 5.0%):** ชะลอความถี่การออกไม้ของคู่นั้น ให้ออกได้ทุก 3 แท่งเทียน
  * **Freeze รายคู่ (DD คู่แตะ 8.0%):** หยุดออกไม้เพิ่มของคู่ที่มีปัญหาทันที
  * **Resume รายคู่ (DD คู่ลดต่ำกว่า 4.0%):** ปลดล็อกกลับสู่โหมดการเทรดปกติ
* [x] **Delta=0 Auto-Hedge Lock (Hard Cap 40.0% DD):** ปราการด่านสุดท้าย เมื่อคู่เงินวิกฤตแตะ 40% ระบบจะคัดเลือกเฉพาะ **คู่ที่แย่ที่สุดเพียงตัวเดียว (Single Worst Only)** แล้วเปิดสถานะสวนทางสุทธิ (Net Delta = 0) ล็อก Drawdown คงที่ทันทีเพื่อป้องกันพอร์ตแตก 100% โดยไม่ทำให้พอร์ตล็อกตายทุกคู่
* [x] **Currency Cluster Limiter (จำกัดสกุลเงินร่วมสูงสุด 3 คู่):** อนุญาตให้ถือครองคู่เงินที่มีสกุลเงินร่วมกัน (เช่น USD, JPY, NZD) พร้อมกันได้สูงสุด 3 คู่เงิน เพื่อกระจายความเสี่ยงและเพิ่มอัตราหมุนเวียน Cash Flow

### 4. ระบบห้องขังเดี่ยว & กู้ภัยขั้นบันไดหลายระดับ (Quarantine & Multi-Tier Cascading Rescue)
* [x] **Event-Driven Adaptive Quarantine [QT] (กักขังเดี่ยวแบบปรับตัวตามพอร์ต):**
  * **Event Trigger:** ทันทีที่ Drawdown รวมของพอร์ตแตะระดับ 28.0% (`PM_FREEZE`) หรือติด SLOW (18.0%) ระบบจะสแกนหาคู่เงินที่ติดลบสูงสุดที่มี DD >= 10.0% (Safety Floor) และสั่งกักขังเดี่ยวทันที พร้อมบันทึกจุดที่เริ่มเข้าขัง (`g_quarantineEntryDD`) ลงใน MT5 GlobalVariable
  * **Standalone Runaway Trigger (14.0%):** หากมีคู่ใดถูกลากหลุดเดี่ยวจน DD แตะ 14.0% (`InpQuarantineSinglePairPct`) จะถูกนำเข้าห้องขังทันทีแม้พอร์ตหลักจะอยู่ในโหมดปกติ (NORMAL)
  * **Isolated Immunity:** คู่ที่ถูกขังจะหยุดถมไม้กริดปกติเพิ่มโดยเด็ดขาด และถูกแยก DD ออกจากพอร์ตชั่วคราว เพื่อไม่ให้ฉุดรั้งพอร์ตหลัก ช่วยให้คู่ที่เหลือยังคงทำกำไรได้
  * **Dual-Mode Safe Release:** ปลดปล่อยคู่เงินออกจากห้องขังเมื่อ DD ลดลงมา $\le 12.0\%$ ในสภาวะพอร์ตปกติ (NORMAL) และปรับเพดานปลอดภัยลงมาเป็น $\le 8.0\%$ (`InpQuarantineSafeCeilingFreeze`) เมื่อพอร์ตติด SLOW/FREEZE ขจัดปัญหาอาการเด้งเข้าออกห้องขัง (Oscillation Trap) 100%
  * **Quarantine Quota:** จำกัดโควตากักขังสูงสุด 3 คู่เงินพร้อมกัน (`InpMaxQuarantinedSymbols = 3`) เพื่อป้องกันวิกฤตเชิงระบบ
* [x] **Multi-Tier Cascading Rescue Grid & Anchor Handover [Build B261014.1 / v2.00-1014]:**
  * **Dynamic Entry Gate & Distance Gate:** ออกไม้กู้ภัยเมื่อ DD คู่เงินแตะ `Quarantine Entry DD + 4.0%` พร้อม Distance Gate ห่างจากไม้สุดท้ายของตระกร้าปกติอย่างน้อย $1.0\text{ ATR (Daily)}$ หรือ 80–100 pips ป้องกันการออกไม้ถี่
  * **100% Price Action Exhaustion Confirmation บนทุกไม้ (R1 ถึง R9):** ตรวจสอบไส้เทียนปฏิเสธราคา (Rejection Wick $\ge 35\%$), แท่งเทียนกลับตัวแท่งแรก, หรือการบีบกรอบแคบ และบล็อกมีดร่วง (Falling Knife / Rocket Spike) ก่อนเปิดไม้กู้ภัยทุกไม้
  * **สถาปัตยกรรมกู้ภัย 3 ระดับขั้นบันได (Tiers 1–3):**
    * **Tier 1 (ไม้ 1–3):** ยิงสไนเปอร์กู้ภัยรอบแรกเมื่อแตะเกณฑ์ Entry + 4%
    * **Tier 2 (ไม้ 4–6):** หากราคายังวิ่งสวนต่อจน DD ลึกเพิ่มอีก $+4.0\%$ จะเลื่อนขั้นสู่ Tier 2
    * **Tier 3 (ไม้ 7–9):** หากยังลากต่ออีก $+4.0\%$ จะเลื่อนสู่ Tier 3 รวมสูงสุดไม่เกิน 9 ไม้ (Hard Cap)
    * **Continuous Ladder Lot:** ล็อตไม้กู้ภัยวิ่งตามสูตร Ladder Lot ต่อเนื่องจากไม้ปกติ โดยมีเพดานกำกับเด็ดขาดไม่เกิน 1.10 lot
  * **Independent Rescue Basket Profit Taking:** ปลดล็อกเงื่อนไขเดิม `count < 3` สามารถปิดรวบทำกำไรชุดกู้ภัยได้ทันทีเมื่อกำไร $\ge 20\text{ Cent}$ ไม่ว่าจะมี 1, 2 หรือ 3 ไม้ แบ่งกำไร $60\%$ เข้า Balance พอร์ตทันที และ $40\%$ เข้า Relief Fund
  * **ระบบส่งต่อไม้ถ่วงสมอ (Anchor Handover at 12% DD):** เมื่อ DD ของคู่เงินลดลงมาแตะ $\le 12.0\%$ ระบบจะหยุด Scalp ชุดกู้ภัย และสงวนไม้กู้ภัยที่ได้เปรียบราคาที่สุด 1 ไม้ (Anchor Order: Buy ต่ำสุด หรือ Sell สูงสุด) ทิ้งไว้เพื่อดึงจุด TP/BE ของตระกร้าปกติทั้งหมดให้ขยับเข้ามาใกล้ราคาปัจจุบัน ปิดรวบทั้งตระกร้าได้เร็วกว่าเดิมมหาศาล!
  * **กฎตัดไม้ติดลบ 3 ต่อ 1 (3-to-1 Profit-to-Trim Rule):** ชุดกู้ภัยต้องปิดทำกำไรสำเร็จครบ 3 รอบก่อน จึงจะดึงเงิน Relief Fund ไปตัดปิดไม้ปกติที่ดอยลึกที่สุด 1 ไม้ รับประกันว่าพอร์ตมี Cash Flow บวกในทุกวันอย่างมั่นคง
* [x] **Cold-Boot State Persistence (ทนทานต่อการรีสตาร์ต VPS):** บันทึกจุดขังเดิม `g_quarantineEntryDD` ลงใน MT5 GlobalVariables (`EMP_Q_ENTRY_<login>_<sym>`) ทำให้ระบบจำสถานะเดิมได้ 100% แม้เครื่องจะรีบูต
* [x] **100% Symbol Freeze Coverage (ปิดจุดบอดคู่ที่ 5 สมบูรณ์):** ขยายระบบ `WorstGridAllowedNow()` ให้ตรวจสอบสถานะ Freeze (DD >= 8.0%) ครอบคลุมทุกคู่เงินในพอร์ต 100% ไม่จำกัดเฉพาะ Top 4 ทำให้คู่เงินใดก็ตามที่แตะ 8% จะหยุดออกไม้กริดทันทีอย่างปลอดภัย

### 5. กองทุนตัดขาดทุนข้ามคู่ (Cross-Pair Relief Fund & Profit Slicing)
* [x] **Profit Slicing Vault (40% Slicing):** ทุกครั้งที่คู่เงินอื่นๆ ปิดทำกำไรได้สำเร็จ ระบบจะหักแบ่งสัดส่วนกำไร 40% โอนเข้าสู่ "กองทุนกลาง (Relief Fund Vault)" สะสมไว้ในหน่วยความจำ
* [x] **Self-Healing Position Trimming:** นำกำไรที่สะสมในกองทุน ไปทยอยตัดปิดขาดทุนไม้ที่แย่ที่สุด (Worst Order) ของคู่ที่ติดอยู่ในห้องขังทีละไม้ โดยที่ Balance รวมของพอร์ตไม่ลดลงและไม่ต้องเติมเงินเข้าพอร์ตแม้แต่บาทเดียว
* [x] **Fund Balance Tracking on HUD:** แสดงยอดเงินกองทุนสะสมที่พร้อมใช้งาน (`FUND: XX.XX`) บนหน้าจอ Dashboard ให้เห็นแบบ Real-time ตลอดเวลา

### 6. ระบบปิดรอบปลอดภัยเมื่อหมดสัญญา (Safe Liquidation Protocol - เอกสิทธิ์เฉพาะ PRIME)

   - **เหตุผลที่นำออก:** แม้ทั้งสองสกุลจะเป็น Commodity Currency แต่ CAD มีความสัมพันธ์แนบแน่นกับราคาน้ำมันดิบโลก (Crude Oil) สูงมาก ในช่วงที่ราคาน้ำมันพุ่งแรง CAD จะแข็งค่าฉีกหนี AUD เกิดเป็น Super Trend ทางเดียว ทำให้กริดติดหล่มและ Drawdown ค้างนาน

   - **พฤติกรรมเดิมใน MAX:** กราฟแกว่งตัวแคบเกินไป (Low Volatility / Narrow Range) สภาพคล่องต่ำ
   - **เหตุผลที่นำออก:** เมื่อ Range ราคาแคบ ทำให้รอบการปิดรวบทำกำไร (Cycle Turnover) ช้ามาก เงินจม และมีความเสี่ยงเรื่องธนาคารกลางสวิส (SNB) เข้าแทรกแซงค่าเงิน รวมถึงค่า Swap ติดลบสูง ไม่คุ้มค่า Margin ในระยะยาว
3. **`GBPCHF`**
   - **พฤติกรรมเดิมใน MAX:** มีความผันผวนกระชากรุนแรง (Extreme Tail Risk)

4. **Table D & Table E:** แสดงข้อมูลจริงส่งตรงจาก HUD ใน MT5 ไม่มีการสุ่มหรือ Hardcode ค่าอีกต่อไป

## 🚀 10. [แผนงานพัฒนา Phase 2 (อยู่ระหว่างการพัฒนา - ยังไม่เปิดใช้งานจริง)]

> ⚠️ **หมายเหตุสำคัญสำหรับทีมงานและการตลาด:**  
> ข้อมูลในหมวดนี้เป็น **"แผนแม่บทการพัฒนาเวอร์ชันถัดไป (Phase 2 Upgrade Roadmap: v2.10+)"** ซึ่งอยู่ระหว่างขั้นตอนการพัฒนาและทดสอบ  
> **ยังไม่ได้เปิดใช้งานจริงในบิลด์ปัจจุบัน (`v2.00 Build B261014.1`)** ที่ลูกค้ากำลังใช้งานอยู่ เพื่อความถูกต้องในการสื่อสาร กรุณาแยกข้อมูลฟีเจอร์ปัจจุบัน (ข้อ 1-9) และแผนงานอนาคต (ข้อ 10) ออกจากกันอย่างชัดเจน

### 1. ระบบควบคุมความเข้มข้นค่าเงินแบบยืดหยุ่น (Dynamic Currency Cluster Shield)
* **เวอร์ชันปัจจุบัน (v2.00 B261014.1):** ล็อกจำกัดสกุลเงินร่วมไม่เกิน 3 คู่ (`Cluster Limit = 3`) คงที่ตลอดเวลา
* **แผนพัฒนา Phase 2:**
  * **โหมด NORMAL ($\text{Active DD} < 18.0\%$):** ปลดล็อก Cluster Limit ให้ทำงานอิสระเสรีเหมือน EasyM MAX ดั้งเดิม (รับได้ 4–5 คู่ตามสัญญาณเทรดจริง) เพื่อเพิ่มความคล่องตัวในการกวาดกระแสเงินสดและกำไรเข้าพอร์ต ไม่บล็อกโอกาสคู่เงินที่สะอาด
  * **โหมด SLOW / FREEZE ($\text{Active DD} \ge 18.0\%$):** สั่งเปิดเกราะควบคุมความเสี่ยง `Cluster Limit = 3` ทันที ป้องกันการกระจุกตัวของความเสี่ยงในยามที่พอร์ตเริ่มตึงเครียด

### 2. สถาปัตยกรรมกู้ภัย 3 ระดับขั้นบันไดพร้อมระบบส่องก้นเหวจริง (3-Tier Cascading Rescue with Smart Exhaustion)
* **เวอร์ชันปัจจุบัน (v2.00 B261014.1):** เมื่อเข้าห้องขัง (14% DD) ต้องรอกราฟลากเพิ่มไปอีก 80 pips และ DD ต้องลบเพิ่มอีก +4.0% จึงจะเริ่มเปิดไม้กู้ภัย R1
* **แผนพัฒนา Phase 2:**
  * **ชุดที่ 1 (R1 - R3: หน่วยจู่โจมก้นเหวแรก):** ทันทีที่เข้าห้องขัง **ปลดล็อกเงื่อนไขรอ +4% DD ทิ้ง** แล้วใช้ `IsRescueExhaustionConfirmed()` ดักจับก้นเหวแรกด้วย Price Action (ไส้ Rejection $\ge 35\%$, แท่งกลับตัว หรือกรอบบีบแคบ) ควบคู่กับ Dynamic ATR Gap (30–40 pips) เพื่อเข้าชาร์จที่จุดต่ำสุด ดึง TP ตะกร้ารวมกลับมาปิดกำไรได้ไวที่สุด
  * **ชุดที่ 2 (R4 - R6: ป้อมปราการแนวรับลึก):** เว้นระยะความปลอดภัย $+4.0\%$ DD จากชุดที่ 1 และต้องผ่านด่านตรวจการกระชากของราคา (Falling Knife Gate) ห้ามรับมีดกลางทางเด็ดขาด
  * **ชุดที่ 3 (R7 - R9: ร่มชูชีพฉุกเฉินสลัดน้ำหนัก):** เว้นระยะความปลอดภัยอีก $+4.0\%$ DD และ **สลับเป้าหมายกำไรไปตัดไม้กู้ภัยชุดที่ 1 ทิ้งเป็นอันดับแรก** เพื่อสลัดล็อตสะสม ลดน้ำหนักพอร์ตฉุกเฉิน ป้องกันไม่ให้แตะ 40% Auto-Hedge

### 3. การแยกคอลัมน์แสดงผลกำไรปกติและยอดตัดกู้ภัยบนแดชบอร์ด MT5 (Table A Split Column)
